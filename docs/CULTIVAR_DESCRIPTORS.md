# Descritores de Cultivares

## Objetivo
Definir o padrão esperado de cada cultivar ou linhagem para apoiar inspeções e identificação de possíveis off-types.

## Exemplo inicial — soja

| Descritor | Exemplo | Momento |
|---|---|---|
| Cor da flor | Roxa | R1-R2 |
| Cor da pubescência | Cinza | Reprodutivo |
| Hábito de crescimento | Indeterminado | Safra |
| Formato da folha | Oval | Vegetativo |
| Cor do hilo | Marrom claro | Pós-colheita |
| Grupo de maturidade | 6.2 | Cadastro |
| Altura esperada | 75–95 cm | Final do ciclo |
| Florescimento esperado | 45–50 DAE | R1 |
| Maturação esperada | 120–125 DAE | R8 |

Características categóricas devem preferir listas padronizadas em vez de texto livre.

A criticidade pode ser classificada como baixa, média, alta ou crítica, sem substituir regras técnicas de aprovação da empresa.

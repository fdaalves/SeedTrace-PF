# Build 001 — Foundation

Versão: 0.1.0-alpha

## Objetivo
Criar o domínio básico do SeedTrace PF antes das operações de campo.

## Escopo
- culturas;
- cultivares;
- descritores varietais;
- padrão esperado por cultivar;
- materiais genéticos;
- lotes e relação lote pai/lote filho.

## Critérios de aceite
- cadastrar culturas;
- associar cultivares às culturas;
- configurar descritores por cultura;
- atribuir valores esperados às cultivares;
- cadastrar materiais genéticos;
- criar lotes com origem rastreável.

## Fora do escopo
Fazendas, talhões, parcelas, inspeções, off-types, roguing, QR Code e colheita entram nas próximas builds.
